## 3. 轮次归档原则

- 第一轮预采集、第二/三/四/五轮执行记录和各自申请已分别归档。
- 每轮授权只对其当时的设备、镜像、时间窗口和操作范围有效；执行窗口用毕即失效。
- 申请文件归档不代表申请已获批；已使用的授权也不延伸至下一轮。
- 事故、身份漂移、失败和恢复不完整记录均保留，不得为“清爽”而删除。
- 当前阶段 A/B 申请与结果单独保留，避免与旧轮次授权混淆。

## 4. 设备操作强制边界

- 65D8 与 C8E4 不可因串口端口号推断映射；须使用当次 boot 后身份锚点和双 console 证据。
- 授权对象优先使用冻结 BIN SHA-256；不能只依赖易随重编变化的 build_sha。
- 端口/设备/镜像/采集链任一身份门禁失败、UNKNOWN 或证据不足，立即 STOP。
- 不允许自动扩大烧录、复位、NVS、配置写入或恢复权限。
