## 1. 双 TTL 时间线（v6 毫秒精度口径不变）

```
trial deadline     = esp_timer_get_time()/1000 + 300000   （store_trial 时刻起）
operation deadline = app_operation_now_ms()   + 300000   （set_state(GOT_IP) 时刻起）
Δ = T1 − T0 实际毫秒间隔（连接/netcheck 在 T0 之前，不计入）
trial deadline 不晚于 operation deadline；Δ>0ms 严格先到期，Δ=0ms 同时到期
T0/T1 无设备侧精确时间戳——主机 monotonic 时钟区间取证（v6 口径不变），
Δ 以测量区间报告
```

## 4. 槽位与操作台账（回收机制勘误 + 前提声明）

| 项 | 口径 |
| --- | --- |
| 本轮创建 operation 总数 | **2**：op-E（expired 观测）+ op-V（job clear 验证，AP_NOT_FOUND 真实失败路径） |

| 槽位占用峰值 | **2/4——前提是无其他仍保留中的历史终态记录**（S0 无法直接清点历史占用，此前提显式声明；出现 busy/no_slot 响应按 §6 STOP） |

| op-V 路径性质 | 受理返回新 id = op-E job 已清的确证；op-V 自身经 `app_cmd_net_async_clear_job_sync()` 清 job/cfg_txn——**不经 cleanup_fn，不作 cleanup_fn 执行证据** |
| 分支①②③④ | 零 op；零 testhook、零人为终态 |

## 6. 异常恢复规则（增补两行，其余不变）

身份漂移/新 boot → STOP（改指向状态先恢复）；BLE 断连 → 重连 ≤3 次 → 失败
按 §5 处置（分支④ 断连清 trial，作废重试至多一次）；cancel 无响应 → 重试
一次 → STOP；GOT_IP 90s 超时 → 重试至多一次；cleanup 后 120s 未恢复 → STOP；
**auth.login 失败 → STOP**；**probe SSID 出现在扫描结果 → 换备用名重验，仍
存在则 job-clear 验证降级并如实标注**；恢复轮询 80s 超限 → STOP；未列明异常
一律 STOP + 恢复 + 归档，不即兴处置。
