**实际存在的 Makefile 测试目录（5 个）**

```

tests/netcheck
tests/wifi_owner
tests/cmd_context
tests/operation_host
```

**命令（逐项执行，记录 rc 与末行）**

```bash
set -uo pipefail   # 不用 -e：falsify 的"通过"本身是非零退出，需单独判定

HOST=artifacts/cmd02_cmd15_verify_20261115/host
mkdir -p "$HOST"

run_zero() {                       # 普通命令：非零即 STOP
    local name="$1"; shift
    echo "===== START: ${name} ====="
    "$@" 2>&1 | tee "$HOST/${name}.log"
    local rc=${PIPESTATUS[0]}
    echo "===== END: ${name} rc=${rc} ====="
    if [ "$rc" -ne 0 ]; then
        echo "STOP: ${name} failed"
        return "$rc"
    fi
}

run_falsify() {                    # 预期非零 + 必须出现 [FALSIFY] OK
    local log="$HOST/operation_host_falsify.log"
    echo "===== START: operation_host falsify ====="
    make -C tests/operation_host falsify >"$log" 2>&1
    local rc=$?
    cat "$log"
    if [ "$rc" -eq 0 ] || ! grep -Fq '[FALSIFY] OK' "$log"; then
        echo "STOP: falsify did not meet its expected failure contract"
        return 1
    fi
    echo "===== END: operation_host falsify expected failure verified ====="
}

run_zero token_store        make -C tests/token_store run        || exit $?
run_zero netcheck           make -C tests/netcheck run           || exit $?
run_zero wifi_owner         make -C tests/wifi_owner run         || exit $?
run_zero cmd_context        make -C tests/cmd_context run        || exit $?
run_zero operation_host     make -C tests/operation_host run     || exit $?
run_falsify                                                      || exit $?

# syntax_check 依赖阶段 1 的 compile_commands.json
run_zero syntax_check  python3 tests/syntax_check.py --strict main/cmd.c main/mqtt.c || exit $?
run_zero s6_gate       .venv-bleak/bin/python tests/s6_gate/test_gate.py            || exit $?
run_zero audit_cs      python3 tests/token_store/audit_critical_sections.py         || exit $?
run_zero check_v1_only .venv-bleak/bin/python tools/ble_p0/check_v1_only.py         || exit $?
```

说明：`run_zero` 用 `PIPESTATUS[0]` 取被测命令的退出码（`tee` 永远成功）；
每条原始输出单独落盘，不只记末行。`run_falsify` 之后显式 `|| exit $?`，不会继续执行后续命令。

说明：

- `syntax_check.py` 依赖阶段 1 产出的 `build/compile_commands.json`；阶段 1 未批准时该项标注"未执行"；
- `.venv-bleak` 是本机虚拟环境（不在仓库内）；若不存在，记录为"环境缺失"，不擅自创建；
- `operation_host falsify` 必须在 `A1` 失败（这是可证伪性检查的预期），其退出码非 0 属通过条件，需按该命令自身输出判定，不能套用"rc=0"。

**验收判据**

1. 上述命令按各自语义通过：Makefile 测试与独立检查 `rc=0`；`falsify` 输出 `[FALSIFY] OK`；
2. 逐项记录断言/用例数（`operation_host` 5 场景 ×50、`s6_gate` 当前基线 141 断言）；
3. 任一失败 → **STOP**，保留原始输出；**不得**通过放宽断言或修改测试来"转绿"；
4. 证据：`artifacts/cmd02_cmd15_verify_20261115/host/`。
