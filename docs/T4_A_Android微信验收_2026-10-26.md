## 4. A 阶段 token 专项（与 #16/#17 对应）

1. 登录拿 token A；发一条受保护命令成功。
2. 错误口令登录：应失败；token A 仍有效。
3. 正确口令重登：token A 失效，新 token B 有效。
4. 断开/重连：token B 失效；重新登录成功。
5. 改密（临时口令，测试后恢复原口令）：
   - 响应含 `sessions_invalidated:true`；
   - 旧 token 下一条命令拒绝；
   - 旧口令登录拒绝；新口令登录成功；
   - 恢复原口令后，临时 token 失效、原口令可登录。
6. 大小写：大写 token 有效；小写 v1 `unauthorized`、v0 `auth_required`；长度错误/非十六进制拒绝。
7. 记录 `expires_in`；600s 完整等待不在 T4-A 重复，TTL 已由 A 阶段 3000ms 专项覆盖。
