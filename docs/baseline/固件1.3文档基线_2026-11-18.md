## 目录职责

| 目录 | 职责 |
|---|---|
| `architecture/` | 当前模块架构、职责、权限与维护边界 |
| `protocol/` | BLE wire 协议及客户端交互参考 |
| `status/` | 当前任务台账、设备验收状态的唯一入口 |
| `design/` | 尚待实施或评审的设计方案与验收要求 |
| `reviews/` | 限定源码基线/审查时点的静态审查与实施证据 |
| `authorization/` | 一次性设备操作授权申请；申请不等于批准 |
| `reports/` | 当前维护集引用的设备回归结果与事故记录 |
| `evidence/` | 镜像、身份、分区、哈希及原始证据 |
| `archive/` | 历史方案、历史验收和冻结快照；不作为当前实现依据 |
| `baseline/` | 当前文档维护基线 |

`validation/` 不再作为混合资料目录；任务状态归 `status/`，设计归 `design/`，审查归 `reviews/`，授权申请归 `authorization/`，历史方案归 `archive/`。
