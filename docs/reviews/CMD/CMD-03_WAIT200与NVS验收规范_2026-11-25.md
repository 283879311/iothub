# CMD-03 WAIT200 与 NVS 验收规范（2026-11-25）

> 文档状态：CURRENT（验收规范）。适用范围：CMD-03 的 WAIT200 有界等待/cleanup 收敛验收，以及 NVS 完整性验收口径。
> 依据：2026-11-25 阶段 B 测量结果与两项正式决策（D1、D2）。本文件不改变 Contract、源码或设备行为。

## 1. WAIT200 验收

### 1.1 时间概念

| 指标 | 定义/冻结值 | 说明 |
|---|---|---|
| 内部等待循环上限 | 20 ticks | `APP_CMD_NET_CLEANUP_WAIT_MS=200`，`CONFIG_FREERTOS_HZ=100` |
| tick 周期 | 10 ms | 同上 |
| 内部循环实测 `elapsed_us` | 记录，不设下限 | 20 ticks 正常耗尽时可小于 200 ms，不构成失败 |
| 全调用墙钟 `T_max` | **250 ms（冻结）** | 第二调用者进入 `app_cmd_net_cleanup_run()` 到该调用返回 |
| cleanup 收敛观察窗口 | 1 s | 观察性验收要求，不宣称实时性保证 |

### 1.2 计时边界

- `T_max` 的计时范围是**整个调用**：从第二调用者进入 `app_cmd_net_cleanup_run()`，到该调用返回。
- 内部 `elapsed_us` 只覆盖 `app_cmd_net_cleanup_wait_result()` 的等待循环，**不能替代**全调用墙钟。
- 验收必须使用能覆盖整个调用的时间戳；超过 250 ms 判为验收失败。
- 不设 `elapsed_us >= 200000` 之类下限；tick 相位导致 20 ticks 约 190 ms 属正常。

### 1.3 判定

- 单次 PASS 仍需满足阶段 B 定义的七项断言（进入等待、返回时 claim=RUNNING、首个 cleanup 后 OK、唯一 cleanup/restore、终态 cancelled/OK、资源清理、无 panic）。
- 全调用墙钟 > 250 ms 判 FAIL；不得以调度因素豁免。
- `waited_ticks < limit` 且返回时 claim=RUNNING 属异常退出路径，判 FAIL 并调查。
- cleanup 收敛超过 1 s 应记录并复核；1 s 是观察窗口，不是实时性保证。

### 1.4 已认可的测量事实（2026-11-25）

- 空闲 10/10、BLE 负载 10/10，单次 PASS 20/20。
- 全调用墙钟 200–210 ms；内部 `elapsed_us` 190130–199809；cleanup 收敛 20–50 ms。
- 证据见 [Phase B 报告](../../evidence/CMD-03_phase_b_wait200_2026-11-25/README.md)。

### 1.5 限制

- 20 次样本不能证明所有调度条件下的最坏执行时间。
- 250 ms 不是 FreeRTOS 调度延迟上限，也不是严格 WCET。
- 不自动适用于其他设备、负载、配置或固件版本；后续超限按真实验收失败记录。

## 2. NVS 验收

### 2.1 口径

| 检查对象 | 验收要求 |
|---|---|
| 应用持久配置命名空间 | 必须一致 |
| 应用凭据及网络配置 | 必须一致 |
| ESP-IDF 系统管理数据 | 单独识别、单独记录变化 |
| `phy/cal_data` | 允许驱动按校准机制更新，但必须记录差异 |
| NVS 整分区 SHA-256 | 仍需记录，不要求所有场景逐字节一致 |

### 2.2 例外边界

- 系统管理数据例外逐次适用，不是永久豁免。
- 出现以下任一情况必须调查，不得套用例外：无法解释的条目变化、其他应用命名空间变化、配置快照不一致、凭据字段变化。
- 整分区 SHA 不一致时必须保留原始哈希与差异摘要，不得改写为一致。

### 2.3 本次历史判定（2026-11-25）

| 项目 | 判定 |
|---|---|
| NVS 整分区逐字节一致 | **FAIL**（`c1e04bc9…` → `849ccdec…`，原始哈希保留） |
| 应用持久配置完整性 | **PASS**（逐键核验 + 配置快照一致） |
| `phy/cal_data` | 存在变化，接受为系统管理数据例外 |
| 配置或凭据被意外修改 | 未发现 |

`phy/cal_data` 两个 blob：1280→1600 字节、624→304 字节；92 个条目/91 个键中仅此键变化。
