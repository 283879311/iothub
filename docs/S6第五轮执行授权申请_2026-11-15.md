## 3. 执行前置门禁（脚本内置，任一失败即 STOP）

串口锚点（各恰 1 处 POWERON）→ 六维身份 ×2（间隔 20s）→ uptime 连续性
（Δu≈Δwall ≤3s、boot 落 19:44–19:46）→ SSID 前置（`302` ≠ 持久 `TQ2026`
≠ 当前 `CMCC-502`）→ **TCP 门禁**（PC→EMQX:1883）→ EMQX RPC 就绪
（CONNACK + 本代 SUBACK，未就绪零 publish）→ 在场监听就绪 → ACL 预检
→ 改指向 → broker 侧确认设备接入 → **稳定性门禁**（连续两次采样；≤120s 严格
deadline）→ op-E。

## 4. 结束状态与退出码

- **0 仅当**：op_e PASS + op_v PASS + 无 abort + `RECOVERY_CONFIRMED`；
- 恢复：R1 会话 / R2 写回（按 `expected_changed_keys` 判 changed）/ R3 独立回读 /
  R4 EMQX 静默 30s（监听就绪前提）/ R5 设备侧二次确认；
  写入被拒 → `RECOVERY_FAILED`；其余无法确认 → `RECOVERY_UNCONFIRMED`；两者均非 0 且不宣称恢复；
- 传输层失败 → `INCONCLUSIVE_TRANSPORT`，不重发 tryconnect、不判为设备失败。
