## 4. 风险与回滚

- **revert 路径**：代码 commit 倒序逐个 revert（`7f86720`→`7f6354e`→`a2c18ff`→`22d29c8`→`969416e`→`f986a72`→`ad495fa`→`0eb30ce`），或整体 checkout 基线源码文件重编（更快）；docs commit 不影响镜像；
- **无状态迁移**：无 NVS 变更、无一次性迁移代码；`CLEANUP_FAILED` 不跨重启保留；
- **已知风险**：fencing 验收中设备可能进入 `CLEANUP_FAILED`（Wi-Fi 离线）→ `config.set + reboot` 或断电恢复；04c 段 B 测试会真实换网——好 SSID 流程结束核对落盘配置，坏 SSID 流程结束核对 rescue 回原配置；
- 单项验收失败 → 只 revert 对应变更重烧，不影响其余三项独立通过。
