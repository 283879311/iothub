# 历史文档归档导航

本目录保存已被新结论取代、已完成的专项材料，以及授权/执行过程的历史原文。归档不代表历史结论无效，也不代表历史授权仍然有效。

## 归档规则

- 当前产品行为：以根目录 [README](../../README.md)、现行协议规范和对应专项主台账为准。
- 当前任务状态：以 [CMD 主台账](../cmd_refactor_plan.md) 及对应专项最新报告为准。
- 历史批准、执行、失败、回滚和事故记录：保留原文，不改写其当时的批准范围和执行结果。
- 被新审查合并覆盖的独立分析：移入归档，并在文件开头标注替代关系。
- 不把归档中的计划或申请当成当前授权；任何新设备操作必须核对最新批准文件。
