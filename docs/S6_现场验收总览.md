- 65D8 与 C8E4 不得按串口端口号推断映射；必须使用当次 boot 后的身份锚点和独立证据。
- 烧录对象以冻结 BIN 的完整 SHA-256 标识；build_sha 仅作辅助反证，不替代 BIN 哈希。
- 设备、端口、镜像、boot 会话或采集链任一身份门禁失败、UNKNOWN 或证据不足，立即 STOP。
- 不得自动扩大烧录、复位、NVS、配置写入、恢复或其他设备操作权限。
- 申请不等于批准；已用完或过期的授权不延续到下一轮。
