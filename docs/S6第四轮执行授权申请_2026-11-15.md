## 4. 结束状态与退出码

- **退出码 0 的唯一条件**：op_e PASS **且** op_v PASS **且** 无 abort **且** `RECOVERY_CONFIRMED`；
- 恢复分阶段 R1–R5（会话/写回+changed 双键/独立回读/EMQX 静默 30s/设备侧二次确认）任一未达成：
  - 写入被拒 → `RECOVERY_FAILED`
  - 其余无法确认 → `RECOVERY_UNCONFIRMED`
  两者均**非 0 退出**，且**不宣称恢复完成**；EMQX 为常驻服务，设备即使仍指向它也可观测、可人工接管写回（不会出现"本地 broker 已停"的坑）。
- 传输层问题（MQTT 超时/断连）→ `INCONCLUSIVE_TRANSPORT`，**绝不重发 tryconnect**，不判为设备失败。
