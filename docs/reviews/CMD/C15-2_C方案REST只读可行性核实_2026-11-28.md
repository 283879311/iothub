## 4. 对 C15-2 判据的影响

| 维度 | 结论 |
|---|---|
| 观察者副作用 | REST GET 不建立 MQTT 会话，Stage-B 的“同 token 第二连接驱逐设备会话”副作用**不再存在** |
| 字段来源 | `net_mode`/`uart_baudrate`/`sta_has_ip` 在 telemetry，约 10 s 一拍且时间戳新鲜；`sta_ssid`/`sta_ip` 只在 attributes（最后上报值） |
| 身份门禁 | attributes 无 `device_id`/`build_sha`，身份仍须由 BLE `device.get` 提供（现有 harness 已具备） |
| 窗口判据 | `net_mode`/`uart_baudrate`/`sta_has_ip` 可用 telemetry timeseries 满足“样本 ts ∈ 窗口”；`sta_ssid`/`sta_ip` 仍只能读最后值，判据需按字段拆分 |
| 权限 | 租户 API Key 为 `TENANT_ADMIN`，不满足只读；用户提供的 `customerC` 账号为 `CUSTOMER_USER`，设备与 attributes 可读、tenant API 403；写能力未测试 |

因此 C 的形态需要重新定义，不能按原设计直接实现。
