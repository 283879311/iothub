## 状态与维护规则

- **ACTIVE**：当前仍被引用的规范、主台账、审查结论或在续证据。
- **PLANNED**：仅有设计/计划，尚未获得实施授权或尚未执行。
- **ARCHIVED**：已完成、被替代或仅供审计回溯；不得当作当前产品行为或当前授权。
- **LEGACY**：明确描述已删除功能或旧版行为；不得作为现行产品能力依据。

1. 新的执行状态只维护在对应唯一主台账/专项报告中；索引不复制长篇进度。
2. 授权与设计分离：设计签收不等于操作授权，代码完成不等于 PASS，授权也不等于执行成功。
3. 不删除有审计价值的授权、执行、失败、回滚和事故证据；真正重复的导航/索引文件可删除，旧内容先归档再移除原入口。
4. 文档更新不改变源码、测试、设备、串口、烧录或 Flash 的授权边界。
