## 归档规则

1. 原文只在归档位置保存，不在顶层复制维护；需要重开专题时创建新版本，不覆盖历史。
2. 每份授权只适用于其原文写明的设备、镜像、时间窗口和操作范围；窗口用毕即失效。
3. 历史 PASS 只代表当时测试范围，不自动代表当前代码/固件 PASS。
4. 不删除独立证据价值的失败、恢复、事故、回滚、镜像 SHA、日志 SHA 和设备身份。
5. 只有纯重复索引、错误副本或无独立事实价值的重复草稿，才允许删除；删除前先核对引用。
